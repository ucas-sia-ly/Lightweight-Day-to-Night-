# 2026-10-15 结果评价

当前工程路径已验证，当前继续训练配方尚未证明全面提高真实夜间泛化。两组恢复权重的独立重测已完成，最终回归为 364 项通过、6 项跳过。分数、协议和对应文件 SHA 见[实验结果](experiment_results.md)；逐 Query 成败变化见[分析记录](../reports/result_analysis_20261015.json)。

| 已评测模型 | MSLS Night R@1 | SVOX Night R@1 | Tokyo Night R@1 | Tokyo Sunset R@1 |
| --- | ---: | ---: | ---: | ---: |
| 完整初始化 | 81.82% | 66.95% | 80.00% | 90.48% |
| Day-only 重训 | 90.91% | 66.95% | 76.19% | 87.62% |
| Day-aug 恢复版本 | 87.27% | 68.04% | 74.29% | 88.57% |

MSLS 只有 55 个夜间 val Query：Day-only 相对初始多找对 5 张，Day-aug 多找对 3 张，不能据此声称对标准完整 MSLS 的泛化提升。Tokyo Night 中 Day-only 新找对 3 张、丢掉 7 张，Day-aug 新找对 2 张、丢掉 8 张，显示继续训练存在收益与退化的交换。

SVOX 的 Day-aug 相对初始新找对 51 张、丢掉 42 张，净增 9 张；R@1 提高约 1.09 个百分点，但 R@5 从 83.48% 降到 82.50%，R@10 从 88.94% 降到 87.24%，MRR 从 0.74156 到 0.74196，变化很小。这更符合部分 Query 排名重排，尚未证明整体候选召回更稳健。Day-only 的 R@1 不变也不是描述子没变化：新找对和丢掉各 47 张。

训练损失下降、有效挖掘的 anchor 约占 22%—25%、完整 optimizer 更新和可重载权重表明训练流程正常；损失下降不等于跨域性能改善。两个方案只用 GSV 白天图像及其光照增强，公开白天验证仅小幅提高，真实夜间多个测试集却退步，提示训练分布与目标分布不一致。预训练特征被继续更新、增强覆盖不足或验证选择不匹配都是待排查假设；单种子、两轮结果不能区分这些原因，也不支持统计显著性声明。

当前推荐保留完整初始化为固定参照，并保留 Day-only 为训练控制组。下一轮优先建立不与已有测试重叠的真实昼夜训练／验证划分；在相同数据和预算下比较只训练聚合器与解冻最后两个 backbone blocks，检查更新 backbone 是否造成迁移能力损失，再单独调整光照增强。新的模型结构应在这些对照清楚之后研究。夜间测试不能用于挑选增强强度、训练轮数或 checkpoint。

544D 描述子与现有推理接口保持一致，初始模型本机 batch-1 CUDA AMP p50/p95 约 2.61/2.90 ms。推理结构没有因这些训练方案增加复杂度，评测延迟差异不能直接归因于训练权重。当前已摆脱训练对 QS-Attn 的依赖；强光、反射、车辆和生成伪影抑制尚无专项证据。公共 Seasons 真值隐藏，只能评价排名输出完整性；Real Night → Fake Night Database 尚无完整测试生成图／映射，因此没有该方向的效果结论。
